# SignGather BSL

**Learn a language. Find your people.**

A responsive website prototype for **SignGather BSL**, a British Sign Language teaching venture being developed by **Tim Scannell** and **Guy Orlov**.

## What SignGather plans to offer

- **BSL Levels 1–3**
- **In-person courses in the Coventry area only**
- **Online courses nationwide using Zoom**

Courses are in development. Dates, fees, venues, entry requirements and any awarding-body/accreditation arrangements have **not** been confirmed.

## What's included

- Responsive landing page with SignGather branding and course information.
- Course finder with level and location/format filters.
- Accessible mobile navigation, visible focus indicators, keyboard-friendly controls and reduced-motion support.
- FAQs about Coventry, nationwide Zoom and planned courses.
- Interactive **enquiry preview**: visitors can enter details, prepare an enquiry and copy the message.

**Important:** This is a prototype, not a production enquiry system. The form **does not submit or store any personal data**. Visitors must copy the enquiry to their own email after an official SignGather contact address becomes available.

## Files

- index.html — main website content
- styles.css — branding, layout and responsive styling
- script.js — menu, course filters and enquiry preview
- favicon.svg — SignGather icon

## Preview locally

There is no build step. Open index.html in a modern browser, or start a simple local server with this terminal command:

    python3 -m http.server 8000

Then visit http://localhost:8000/.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this GitHub repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Once GitHub finishes deploying, visit: https://guyorlov.github.io/signgather-bsl/

> The Pages address is an expected URL, **not proof of an active deployment**. You must enable Pages in repository settings first.

## Before launching publicly

1. Confirm the actual course timetable, locations and prices.
2. Confirm whether programmes will lead to an accredited qualification, and state that accurately.
3. Add a verified business contact address and working enquiry-handling process, then review data protection/privacy notices.
4. Review the website with Tim and test it across mobile, desktop and keyboard navigation.
5. Replace the prototype message generator with a properly configured and privacy-compliant contact form or clearly published email address.
